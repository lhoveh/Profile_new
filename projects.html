Botafogo All-Stars

 I created a small soccer field here, replicating the page design from Globo.com using vanilla JS and CSS. It was my first experience. I started with inline commands and DOM manipulation. Later, I progressed to JS object manipulation for player lists (arrays) and categories.

Some commands/automations still need improvement. In the future, database integration could be explored. There's also a section solely for player profiles, where I practiced replicating the design of an existing website but using my own content. I also worked on responsiveness.

Game

 A silly little game based on Alcatraz. You move the character, pick up objects in the cell, and do everything with a mouse, keyboard, or touching the screen. Super basic, just for testing. The images were created using artificial intelligence.

I've used CSS and JS only here, but I also used Midjourney for the images, and some AI help to create the functions that allow the character movements. I'll study these functions further to better understand what was done. Everything else, including responsiveness, was manual work done by me.

Botafogo Portal

 Here, I’m really exploring AI. I come up with the idea and act as the creative director, using ChatGPT for the CSS and HTML code and making only the adjustments. I work with AI to achieve design results based on my guidance.
